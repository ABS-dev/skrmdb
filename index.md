# skrmdb

Package to estimate ED50 by the methods of Spearman-Karber, Reed-Muench,
and Dragstedt-Behrens.

## Installation

### Using `{pak}`

    # Install latest version
    pak::pak("ABS-dev/skrmdb")

    # Install an older version
    pak::pak("ABS-dev/skrmdb@4.5.0")

### Using `{devtools}` (Version 2.4.6 or earlier)

    # Install latest version
    devtools::install_github("ABS-dev/skrmdb")

    # Install an older version
    devtools::install_github("ABS-dev/skrmdb", ref = "4.5.0")
