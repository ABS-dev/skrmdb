# print.skrmdb

A print generic for a `skrmdb object`

## Usage

``` r
# S3 method for class 'skrmdb'
print(x, rnd = 3, verbose = TRUE, ...)
```

## Arguments

- x:

  An object of class `skrmdb`.

- rnd:

  The number of digits to round the numeric values.

- verbose:

  If `TRUE`, prints out messages to help interpret the last five columns
  of the printed table.

- ...:

  Additional parameters.

## Value

The `results` table in `x`, invisibly.
